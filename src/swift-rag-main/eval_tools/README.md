# 评估工具 (eval_tools) 使用说明

## 简介

`eval_tools` 是一个用于评估检索增强生成（RAG）系统检索阶段效果的工具集。它能够通过比较检索结果与标注数据，评估RAG系统的召回能力，帮助开发者分析和改进检索模块。

## 主要功能

- 从Excel文件读取测试数据和检索结果
- 评估检索结果的召回效果
- 支持多种字符串匹配算法（最长公共子串、最长公共子序列）
- 详细分析未命中查询，便于问题定位和优化

## 文件结构

```
eval_tools/
├── README.md           # 使用说明文档
├── eval_chunk.py       # 主要评估脚本
└── data/               # 数据目录，用于存放测试数据和评估结果
```

## 使用方法

### 安装依赖

```bash
pip install pandas openpyxl
```

### 准备数据

准备一个Excel文件，包含以下必要字段：
- `问题`：查询文本
- `问题来源段落截取`：标注的原文段落
- `问题文件来源`：问题出处文件名
- `search_list`：检索结果列表（Python字典格式的字符串）

### 运行评估

```bash
python eval_chunk.py --file_path 数据文件路径 --sheet_name 表格名称 --threshold 匹配阈值 --output_file 输出结果路径
```

参数说明：
- `--file_path`：Excel数据文件路径，默认为`eval_tools/data/呈贡RAG层测试集v0.1.xlsx`
- `--sheet_name`：Excel表格名称，默认为`20250401 internlm 20b chat`
- `--threshold`：匹配阈值，范围0-1，默认为0.8
- `--output_file`：评估结果输出路径，默认为`eval_tools/data/eval_results.xlsx`

### 评估结果解读

评估脚本会输出以下信息：
- 总查询数
- 命中数
- 召回率
- 详细的未命中查询分析

结果会保存为Excel文件，包含原始数据及以下附加字段：
- `是否命中`：1表示命中，0表示未命中
- `最匹配的检索结果`：与原文段落最匹配的检索结果
- `最长匹配`：原文与检索结果的最长公共部分
- `最长匹配比例`：最长匹配占原文的比例
- `最长匹配长度`：最长匹配的字符数

## 核心算法

该工具提供两种字符串匹配算法：
1. **最长公共子串**：查找两个字符串中连续出现的最长相同部分
2. **最长公共子序列**：查找两个字符串中相对位置不变的最长相同字符序列

默认使用最长公共子序列进行匹配，这对文本段落中有轻微修改或格式变化的情况更为宽容。

## 示例

```bash
python eval_chunk.py --file_path ./data/my_test_data.xlsx --sheet_name "测试结果" --threshold 0.7
```

## 注意事项

- 确保Excel文件中的`search_list`字段格式正确（可用Python的`ast.literal_eval`解析）
- 匹配阈值设置影响召回率评估，建议根据实际需求调整
- 预处理会移除换行符和空格，以提高匹配准确性

## 常见问题

- 如果遇到解析错误，请检查`search_list`字段格式
- 如果召回率过低，可以尝试降低匹配阈值或检查检索系统配置
